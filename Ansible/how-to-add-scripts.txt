How to add scripts for Ansible deployment
=========================================

1) Put Linux scripts in:
   scripts_linux/

2) Commit your new script files to the repo.

3) Run the playbook:
   ansible-playbook -i <inventory> Ansible/install-scripts.yml

Default install locations:
- Linux targets: /opt/irsec/scripts

Current post-install behavior on Linux targets:
- Runs /opt/irsec/scripts/inventorier.sh once during playbook execution
- Installs and starts watch.sh as systemd service: irsec-watch
